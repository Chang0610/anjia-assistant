1. 产生就业搬迁需求

3. 输入自然语言问题

例如：我 10 月入职，预算 3,500 元，帮我安排搬家计划

10. 查看回答并作出决定

阅读近期事项、理由、时间、前置、完成标准和来源

11A. 确认或取消日程提议

确认后写入；取消或继续补充时不覆盖原日程

12. 继续追问或反馈变化

改期 / 删除 / 已找到住处 / 交房延期 / 标记完成

13. 管理资料与历史

更正资料、查看历史输入、清空本地数据

2. 展示安家助手入口

底部导航进入；展示首次引导、推荐问题与历史对话

4. 接收输入并组装请求

带入本地资料、近期对话、confirmed 与 pending 日历

9. 展示 AI 回答

纯文本答案、证据入口、快捷选项；日程提议置于回答之后

判断是否包含 proposal

普通咨询：仅回答；计划或变更：展示本次新增、修改、删除

11B. 写入计划日历

确认后将 pending 写入 confirmed；刷新月历与日期待确认区

发起新一轮请求

沿用资料和当前日历；只提交用户明确要求的变更

更新本地状态

资料 / 聊天 / 日程 / 提醒偏好保存在当前浏览器

5. 请求校验与资料合并

校验消息格式；只合并用户明确提供或更正的个人事实

6. 意图与回答模式识别

信息采集 / 单事项建议 / 计划生成 / 日程变更 / 冲突核验

7. 上海知识检索与筛选

按城市、事项、身份、状态检索；区分 verified、pending、sample

8A. Prompt 编排与模型生成

生成简洁回答、追问、profile_updates 与 operations

8B. 日程校验与结果后处理

日期、去重、依赖、硬截止校验；构建 proposal 与证据标注

确认结果不回写服务端日历

当前原型由前端本地保存；服务端只返回候选变更

重新识别并生成

结合最新用户信息和 confirmed/pending 状态调整回答或日程

评测、来源与风险控制

来源状态、回答质量、幻觉、越权与敏感误答持续监控
